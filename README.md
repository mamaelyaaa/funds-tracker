# Трекер капитала

Система для отслеживания личного капитала и доходов.

## Быстрый старт

Для локального запуска должно быть установлено:

- **Docker**
- **GNU Make** или **WSL** для работы с make (рекомендуется, но не обязательно)

### 1. Клонирование репозитория

```bash
git clone https://github.com/mamaelyaaa/funds-tracker.git
cd funds-tracker
```

### 2. Настройка окружения

Создайте файл `.env` на основе `.env.example`. В большинстве случаев значения по умолчанию подходят для локального
запуска.

```shell
cp .env.example .env
```

### 3. Запуск сервисов

В приложении используется `Makefile` как обертка над Docker, Python командами для упрощения работы

```shell
# Сборка образов (для первого запуска и в случае изменения Dockerfile)
make build    

# Запуск всех контейнеров в фоновом режиме
make up       
```

Все доступные команды описаны в `Makefile`. Посмотреть список можно командой:

```shell
make
```

> При отсутствии make использовать основные команды `docker compose`

## Аутентификация и авторизация

Бекенд использует пару токенов **Access** (headers) + **Refresh** (cookie) для аутентификации и авторизации

Для регистрации и авторизации

### Токен доступа

Токен выпускается с помощью запросов `/auth/register` и `/auth/login`. Для дальнейшего использования, ко всем
последующим запросам на сервер нужно прописывать **headers**:

```json
{
  "Authorization": "Bearer <ACCESS_TOKEN>"
}
```

### Токен обновления

Токен обновления используется в запросе `/auth/refresh` для обновления токена доступа. Запрос на этот эндпоинт должен
подтягивать cookie:

```shell
# Axios
const api = axios.create({
  baseURL: 'http://localhost:8000', 
  withCredentials: true,  # Обязательно
});

# Или для отдельного запроса
await api.post('/auth/refresh', {}, {
  withCredentials: true
});


# JS
await fetch('http://localhost:8000/auth/refresh', {
  method: 'POST',
  credentials: 'include', # Обязательно!
});
```

Куки направляются только на `/auth/*` запросы, на других путях _**токен будет невидимым**_

> В случае ошибок с получением куки, возможно стоит **проксировать API**
